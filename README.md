# Portfolio - Assignment 1

## Project Description
This is a simple, responsive personal portfolio website built with HTML, CSS and JavaScript. It has an About Me section, a Projects section with two projects, and a Contact form. It also includes a time-based greeting and a dark/light mode button.

## Setup Instructions
No installation is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/LayanAlomari/202351790-LayanAlomari-assignment1.git
   ```
2. Open the project folder:
   ```bash
   cd 202351790-LayanAlomari-assignment1
   ```
3. Open `index.html` in your browser.
